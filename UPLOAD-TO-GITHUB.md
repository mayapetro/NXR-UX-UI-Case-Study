# Put this on GitHub (no coding needed)

1. Sign in at github.com → **+** (top right) → **New repository**.
   Name it e.g. `nxr-case-study`, set **Public**, tick **Add a README** only if you plan to replace it (easier: leave unticked), click **Create repository**.
2. On the empty repo page click **uploading an existing file**.
3. Unzip this kit on your computer, then drag the **contents** of the `nxr-github` folder into the browser
   (index.html, README.md, .nojekyll, and the folders prototype, prototype-slides, images).
   Note: `.nojekyll` can be hidden on your computer; if you can't see it, skip it – the site still works.
   Folders upload correctly if you drag them in from your file explorer.
4. Click **Commit changes**.
5. Go to **Settings → Pages**. Under **Build and deployment**, set Source = **Deploy from a branch**, Branch = **main**, folder = **/(root)**, **Save**.
6. Wait 1–2 minutes. Refresh Settings → Pages: it shows your live address
   `https://YOUR-USERNAME.github.io/nxr-case-study/`
7. Edit README.md (pencil icon): replace YOUR-USERNAME and REPO-NAME with yours, and fill in role/tools/timeline.
8. Use those addresses in Adobe Portfolio or on your résumé. The prototype is at `/prototype/`.

Notes
- The repo must be Public for GitHub Pages on a free account.
- Each HTML file is self-contained (images and fonts inside), so nothing else is needed.
